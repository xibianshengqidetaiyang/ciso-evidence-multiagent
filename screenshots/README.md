# Screenshots

This directory is reserved for sanitized demo screenshots.

Do not upload screenshots containing:

- real customer names;
- internal IP addresses;
- usernames, passwords, tokens or cookies;
- real assessment IDs;
- real evidence file names;
- contracts, audit reports or customer confidential documents.

Recommended sanitized screenshots:

```text
01_run_log_demo.png
02_ciso_overview_demo.png
03_evidence_mapping_demo.png
04_observation_summary_demo.png
05_manifest_demo.png
```

Suggested screenshot content:

1. running command in dry-run mode;
2. CISO Assistant demo assessment overview;
3. evidence attached to a demo control;
4. control-level Observation summary;
5. sanitized manifest output.
