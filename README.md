# CISO Evidence Multi-Agent

基于 CrewAI、Ollama 与 CISO Assistant API 的安全合规证据自动处理原型。

## 项目简介

本项目面向等保/合规审计场景，尝试将证据处理流程拆分为多个角色，覆盖证据有效性校验、控制项分类、API 自动导入、AI 初审、单文件整改建议以及整批整改建议总报告输出。

项目目标是把“证据读取 -> 控制项匹配 -> 证据导入 -> 初审分析 -> 整改建议”串成一个可运行闭环，用于审计前预检查、补证辅助和整改优先级分析。

## 项目效果

- 支持批量处理 52 份测试证据文件，全部完成流程处理。:contentReference[oaicite:0]{index=0}
- 支持生成按控制项汇总的整改建议总报告，输出主要问题、缺失证据、建议补充文件、优先级建议与预计提分区间。:contentReference[oaicite:1]{index=1}

## 核心能力

- 多类型证据读取与最小有效性筛选
- 基于本地 Ollama 的 requirement 分类
- 通过 API 自动导入并绑定控制项
- AI 初审与单文件整改建议输出
- 批量汇总整改建议总报告生成
