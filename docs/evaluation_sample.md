# Evaluation Sample

## 1. 评估目的

本评估用于验证证据自动分类和挂接建议的可用性，不用于证明系统可以完全替代人工审核。

评估关注：

- Top-1 命中情况；
- Top-3 命中情况；
- 是否存在明显误挂；
- 应跳过文件是否被正确跳过；
- 人工是否可以接受该候选结果。

## 2. 评估方法

建议抽样 30 份证据：

| 类型 | 数量 | 说明 |
|---|---:|---|
| 制度类 | 10 | 管理制度、程序文件、手册 |
| 记录类 | 10 | 签到表、检查表、审批表、报告 |
| 表格类 | 5 | XLS/XLSX 台账和清单 |
| 低相关/应跳过类 | 5 | 与控制项弱相关或暂不支持格式 |

## 3. 评估表模板

| 序号 | 文件名 | 证据类型 | 人工期望控制项 | 系统 Top-1 | 系统 Top-3 | 是否命中 | 是否误挂 | 是否应跳过 | 备注 |
|---:|---|---|---|---|---|---|---|---|---|
| 1 | employee_handbook_demo.md | 制度类 | 2.1.2 / 2.1.3 | 2.1.3 | 2.1.3 / 2.1.2 / 8.2.3 | 是 | 否 | 否 | 员工培训和承诺均相关 |
| 2 | asset_classification_demo.md | 制度类 | 1.3.1 / 1.3.2 | 1.3.1 | 1.3.1 / 1.3.2 | 是 | 否 | 否 | 资产识别和分类相关 |
| 3 | access_log_review_demo.csv | 记录类 | 5.2.4 | 5.2.4 | 5.2.4 / 4.1.3 | 是 | 轻微 | 否 | 同时包含账号复核信息 |
| 4 | incident_report_demo.md | 记录类 | 1.6.2 / 9.6.2 | 1.6.2 | 1.6.2 / 9.6.2 | 是 | 否 | 否 | 事件处理证据 |

## 4. 指标计算

```text
Top-1 命中率 = Top-1 正确命中数量 / 样本总数
Top-3 命中率 = Top-3 中包含人工期望控制项的数量 / 样本总数
误挂率 = 存在明显错误候选的样本数量 / 样本总数
跳过正确率 = 应跳过且被跳过的样本数量 / 应跳过样本数量
人工可接受率 = 人工认为候选结果可用于复核的样本数量 / 样本总数
```

## 5. 示例结论写法

> 在 30 份样本评估中，记录类和表格类证据的候选结果更稳定，制度类和管理手册类文件由于覆盖范围较广，容易匹配多个控制项。当前系统适合作为 AI 初筛和人工复核辅助工具，不建议直接替代最终审核结论。后续可通过控制项族群约束、导入前人工确认界面和更细粒度规则继续降低误挂率。

## 6. 主要误判来源

1. 综合制度文件覆盖范围过广；
2. 控制项标题存在相似语义；
3. 证据正文中包含大量通用安全词；
4. Excel 表格字段较少时上下文不足；
5. 暂不支持的格式可能导致解析内容不足。

## 7. 后续优化建议

- 增加控制项族群约束；
- 将 `FINAL_TARGET_TOP_K` 从 10 调整为 5 做更保守演示；
- 增加导入前人工确认页面；
- 增加 PPTX / ZIP / EML 解析；
- 引入人工标注集持续评估分类效果。
