# Information Security Incident Report Demo

## Incident Overview

Incident ID: IR-2026-001  
Date: 2026-01-08  
Reporter: IT Service Desk  
Incident Type: Suspicious email attachment  
Affected System: Employee workstation

## Handling Process

1. The suspicious email was reported by the employee.
2. The IT team isolated the workstation for verification.
3. Endpoint protection logs were reviewed.
4. No malware execution was detected.
5. The email sender and attachment hash were added to the monitoring list.

## Corrective Actions

- Update phishing awareness material.
- Remind employees to report suspicious emails.
- Review email gateway filtering rules.
- Retain handling record and closure confirmation.

## Closure

The incident was closed after verification. No business interruption was observed.
